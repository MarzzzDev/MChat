FAQ

Setup, commands and privacy in one place.

What is MChat?

MChat is a browser-source chat overlay for Twitch, Kick and YouTube, with third-party emotes and badges. It is made by marz_dev; the source is on GitHub.

How do I get my overlay URL?

Enter your channels and adjust the preview on the setup page, then select Copy overlay link. Paste it into an OBS Browser Source. The URL includes your channels and settings.

Who made MChat?

MChat is an independent hobby project by marz_dev, not affiliated with its supported platforms or services.

Why do my setup settings stay after I refresh?

Your latest overlay link is saved in your browser. Use Reset settings to restore defaults; -reset clears chat command overrides.

Chat commands

Broadcasters can always use commands. Moderators can use -refresh and -modcommands anytime; enable Mod commands in setup for the rest. Select a command to copy it, then add a value if shown.

Commands start with -. Boolean values accept on/off, true/false, yes/no or 1/0; omitting one toggles it. Numeric values use the listed ranges.

Privacy & security

MChat has no account system and does not request or store Twitch login tokens. Your channel names and settings are in the overlay URL; setup saves that URL in your browser to restore it next time.

Chat is processed in your browser and MChat does not keep chat history. Some requests use MChat’s proxy; others connect directly to chat platforms and asset providers. Those services and the site host may receive your IP address and standard request data under their own privacy policies.

MChat does not use analytics or session recording. Moderator overrides are stored locally for the matching overlay URL and can be removed with -reset.
